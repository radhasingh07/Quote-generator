# 💬 Quote Generator

A responsive Quote Generator built using HTML, CSS, and JavaScript. This web application displays random inspirational and motivational quotes through a clean, modern, and user-friendly interface.

## ✨ Features

- Generate random quotes
- Display quote author
- One-click quote refresh
- Responsive design
- Clean and modern user interface
- Fast and lightweight application

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Quote-Generator/
│── index.html
│── style.css
│── script.js
│──main.png
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 How to Use

1. Open the application.
2. Click the **Generate Quote** or **New Quote** button.
3. Read the displayed quote.
4. Click the button again to generate another random quote.

## 🎯 Use Cases

- Read daily motivational quotes
- Learn JavaScript DOM manipulation

- Improve front-end development skills
